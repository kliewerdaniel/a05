# Brand Identity & Visual Guidelines

## Brand Architecture

The brand operates as a single entity: **Daniel Kliewer** — the person IS the brand. There is no separate company name or DBA. This is intentional: personal brands convert at higher rates for consultancy because clients buy trust in an individual.

### Brand Name Usage

| Context | Format |
|---|---|
| Display / hero | "Daniel Kliewer" |
| Tagline always paired with name | "Daniel Kliewer — AI Infrastructure & Systems Engineering" |
| Copyright / footer | "Daniel Kliewer" |
| URL / social handle | `kliewerdaniel` |
| Professional shorthand | "Daniel" (in blog posts, newsletter) |

### Tagline System

- **Primary:** "Local AI Infrastructure. Production Systems. Technical Authority."
- **Short form:** "AI Infrastructure & Systems Engineering"
- **Elevator pitch:** "I help businesses deploy private, local-first AI infrastructure — knowledge systems, workflow automation, and production-ready AI applications."

---

## Logo & Wordmark

No logo. The name IS the logo. This eliminates the cost of design, the complexity of responsive logo variants, and the inconsistency of logo usage.

### Wordmark Rules

- Always set in Inter Bold or Heavy
- Never distort, stretch, or rotate
- Minimum size: 16px (screen), 0.5in (print)
- Clear space: height of the "D" on all sides
- On dark backgrounds: white (#ffffff)
- On light backgrounds: near-black (#0a0a0b)
- On images: use a semi-transparent backdrop blur or skip

### Favicon

A monogram-style "DK" in Inter Bold, white on #0a0a0b, rendered as SVG favicon with dark background tile.

## Color Palette

See `/design-system/color-philosophy.md` for the full color system. Brand-specific color usage:

| Color | Usage | Hex (Dark) | Hex (Light) |
|---|---|---|---|
| Background | Page background | `#0a0a0b` | `#ffffff` |
| Foreground | Primary text | `#fafafa` | `#09090b` |
| Brand accent | Primary CTA, links, highlights | `#3b82f6` (blue-500) | same |
| Success | Metrics, positive outcomes | `#22c55e` | same |
| Surface | Cards, raised elements | `#141415` | `#f4f4f5` |
| Border | Subtle dividers | `#27272a` | `#e4e4e7` |

### Accent Color Rules

- Blue (`#3b82f6`) is the ONLY accent color on the site
- Use it for: primary buttons, links, hover states, metric highlights
- Do NOT use: multiple accent colors, gradient accents, color-coded categories
- Exception: semantic colors (green for success, amber for warnings, red for errors) are permitted for their semantic meaning only

## Visual Density

- **Low density** on pages, high density in content
- Hero sections: maximum whitespace, minimal elements
- Blog posts: dense but readable (72ch, comfortable line-height)
- Cards: compact but not cramped
- Navigation: spacious (48px height minimum)

## Brand Applications

| Application | Key Brand Elements |
|---|---|
| Business cards | Name, tagline, URL, GitHub handle. Minimal. Dark background. |
| Slide decks | Dark background, Inter throughout, metrics in blue accent |
| Email signature | Name, title, URL. Plain text preferred over HTML. |
| Social media headers | Dark background, name + tagline, no logo |
| GitHub profile | Name, tagline, pinned repos for services |
| YouTube thumbnails | Dark background, bold text overlay, consistent framing |

---

## What the Brand Does NOT Look Like

- No stock photography of "futuristic AI" (glowing brains, robot hands, circuit boards)
- No corporate stock photos of people shaking hands
- No abstract 3D renders of geometric shapes
- No AI-generated "art" for hero backgrounds
- No gradients for the sake of gradients
- No brand mascots or abstract symbols
