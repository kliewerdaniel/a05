# Voice & Tone Guidelines

## Brand Voice Definition

**Voice:** Direct. Technical. Personal. Confident without arrogance. Clear without simplification.

**Archetype:** The Architect-Philosopher — someone who builds systems AND thinks deeply about what they mean.

### Voice Dimensions

| Dimension | Position | Description |
|---|---|---|
| Formal vs Casual | Leans casual | Contractions, first-person, conversational rhythm. But always precise. |
| Technical vs Accessible | Bilingual | Fluent in technical jargon, but always translates for the reader. Default to technical, explain when needed. |
| Serious vs Playful | Serious, with warmth | This is business, but not cold. Professional without being corporate. |
| Enthusiastic vs Reserved | Reserved | Let the results speak. No hype, no superlatives, no exclamation points. |
| Abstract vs Concrete | Concrete | Specific over general. Show numbers, show code, show architecture. |

## Tone by Context

| Context | Tone | Example |
|---|---|---|
| Blog - Technical | Direct, precise, teaching | "Here's how to deploy Ollama behind a reverse proxy with GPU passthrough." |
| Blog - Philosophical | Contemplative, first-person | "I've been thinking about what happens when AI infrastructure is owned vs rented." |
| Homepage | Authoritative, benefit-forward | "Production AI systems for organizations that control their stack." |
| Services | Consultative, specific | "You get a working RAG system deployed on your infrastructure in 2 weeks." |
| Case Studies | Factual, results-oriented | "Reduced manual review time by 73% with an automated document classification pipeline." |
| About | Personal, narrative | "I started building AI systems because I wanted to understand how they actually work." |
| Contact | Helpful, low-pressure | "Tell me about what you're building. No pitch, no pressure." |
| Resources | Generous, instructional | "A step-by-step guide to deploying your first local LLM." |
| Newsletter | Conversational, personal | "Here's what I've been working on and thinking about this week." |
| Error / 404 | Apologetic, brief, helpful | "Page not found. Here are some popular posts instead." |

## Voice Rules

### 1. Show, Don't Tell
- Bad: "I'm an expert in AI systems"
- Good: "I built a RAG system that processes 10,000 documents a day with 94% accuracy"

### 2. Specific Over General
- Bad: "I help businesses with AI"
- Good: "I help B2B SaaS companies build private knowledge bases that their teams actually use"

### 3. Active Voice Always
- Bad: "The system was built using..." 
- Good: "I built the system using..."

### 4. Short Sentences
- Max 25 words per sentence as a target.
- Break complex ideas into multiple sentences.
- One idea per sentence.

### 5. Technical Precision
- Use correct terminology (RAG, fine-tuning, embeddings, etc.)
- Define terms on first use if the audience might not know them
- Never dumb down. Clarify instead.

### 6. No Hype Words

| Don't Use | Use Instead |
|---|---|
| revolutionary | effective |
| game-changing | significant |
| cutting-edge | modern |
| AI-powered | AI-integrated |
| state-of-the-art | production-grade |
| leverage | use |
| utilize | use |
| transformative | different |
| disrupt | change |
| best-in-class | well-built |
| innovative | — (show the innovation instead) |

### 7. Write for Scanning
- Short paragraphs (2-4 sentences max on web)
- Descriptive subheadings
- Bullet lists for parallel items
- Bold for key terms (not entire sentences)
- Code examples where appropriate

## CTA Language Patterns

| Context | CTA | Tone |
|---|---|---|
| Hero section | "Book a Free Consultation" | Direct, low-friction |
| End of case study | "Want results like these?" | Curiosity-driven |
| End of blog post | "Building something similar? Let's talk." | Relevant, specific |
| Services page | "Start the Conversation" | Consultative |
| Newsletter | "Get monthly AI insights" | Value-forward |
| Resource download | "Get the Guide" | Direct |
| Contact page | "Tell Me About Your Project" | Open, inviting |
| About page | "Work With Me" | Personal |
| General secondary | "Learn More" | Safe default |

## Prohibited Language

- "Unlock the power of AI"
- "Supercharge your workflow"
- "AI-driven" (use "AI-integrated" or be specific)
- "Next-gen" / "Next-generation"
- "Seamlessly" (always)
- "In today's fast-paced world"
- "Harness the power"
- "Revolutionize"
- "Game-changer"
- Any cliché about "the future is here"

---

## Capitalization & Punctuation

- **Headlines:** Sentence case (not Title Case). Exception: proper nouns, acronyms.
- **Buttons:** Sentence case. "Book a consultation" not "Book A Consultation".
- **Exclamation points:** Never in marketing copy. Extremely rare in blog posts. Only in personal/community contexts.
- **Periods in lists:** Yes for complete sentences. No for fragments.
- **Em-dashes:** Spaced (word — word). Used sparingly for dramatic pauses.
- **Quotes:** Curly quotes in prose. Straight quotes in code.

---

## International & Accessibility

- Write for an international English-speaking audience
- Avoid US-centric idioms and cultural references
- Define acronyms on first use (even common ones like "RAG")
- Use plain language where possible
- Spell out numbers 1-9, use numerals for 10+
- Write dates as "May 24, 2026" (Month DD, YYYY)
- Use "they/them" as singular pronoun when gender is unknown
